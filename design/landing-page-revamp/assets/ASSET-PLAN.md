# Standalone artwork production

Generate original artwork only, with no UI, interface text, branding, frames, screenshots or readable lettering. This separates assets from the existing composite mockups. Runtime work and HTML/Python testing are outside this task.

The user's correction selects **HERO V7 for all five themes**: Akshara, Astra, Neel, Sabha and Vanam. Those five screenshots were inspected directly. The earlier v8-based standalone portraits are superseded drafts. All eight capability/output v10 mockups were also inspected; their existing character-free background assets are retained, with matching Vanam assets added.

## Theme direction

| Vanam | V7 Vyasa/Krishna banyan manuscript scene; celadon, forest/emerald, ochre, burnt orange and brass. |

The approved refined matte art finish is retained; palettes and subject worlds follow each v7 reference. Geometry is crucial: the future native workspace begins within the 40–50% height region, so the focal faces and working gestures must remain above its edge. Some supporting tabletop detail can sit behind that workspace. Copy uses a naturally calm part of the upper-left scene; no painted white block, corner cutout or interface placeholder.

Detailed prompts live under each theme's `assets/prompts/`. Selected original PNGs live under the same theme's `assets/`; final links and review notes are recorded in the standalone asset index. Original composite mockups remain preserved. Only the new hero references change selection; the existing character-free lower assets are not arbitrarily repainted.

## Visual review

Inspect each rendered image for coherent perspective and materials, natural faces/hands, restrained detail, clear theme identity and suitability for its intended crop. Reject visible UI/lettering, tangled objects, generic glossy fantasy rendering, decorative clutter and focal subjects that would be hidden by the planned UI. Selection is an agent design decision, not user approval or implementation proof.
