## Placement and selection

- Hero assets are full-page backgrounds. Keep their aspect ratio and choose positioning so the native workspace begins within the intended 40–50% region without hiding focal faces or working hands. Do not reuse them as small top-right picture cards. The selected image's precise crop should guide placement.
- Capability assets support different crops around opaque native feature previews. Use the separate archive detail for history to avoid repeating a single illustration across every preview.
- Outputs backgrounds have calmer centers for report/deck previews and FAQ. The large output surfaces remain native UI, separate from the decorative painting.
- Existing lower assets were retained after the user's correction; changes focus on hero composition plus the missing Vanam set. The v7 source screenshots remain untouched.
- These are selected source images, not implemented layout, responsive QA or performance proof. No HTML or Python testing was used in this artwork task. Native dimensions above are actual returned sizes, not the larger requested sizes. No artificial upscaling was applied.
